# Time Bounce

DO NOT EDIT THIS BRANCH,
it has version of the game that was submitted at the end of the hackclub haven 2026 game jam

A short puzzle platformer, where you can bounce back in time and solve puzzles using the past versions of yourself.

Inputs (can change from WASD to ARROWS in settings):

    W/UP - jump
    A/LEFT - left
    D/RIGHT - right
    F/Z - interact
    1,2,3,4/a,s,d,f - change save slots
    Q/C - record
    E/X - play recording
    R - restart
